# MY COLLECTION

Личная коллекция фильмов, сериалов и мультфильмов: оценки, отзывы, трейлеры, ТОП-100 и свои списки.

**Сайт:** https://h0usehome.github.io/top_films_by_me/

## Как устроено

Статический сайт на GitHub Pages без сборки. Данные хранятся в Supabase, постеры и трейлеры ищутся через TMDB.

| Файл | Назначение |
|---|---|
| `index.html`, `app.js`, `style.css` | Публичная витрина |
| `admin.html` | Добавление и редактирование записей, порядок ТОП-100 (`#top100`) |
| `database.html` | Вся база: поиск, удаление, автопоиск трейлеров |
| `lists.html` | Управление своими списками |
| `config.js` | Публичные ключи Supabase и TMDB |
| `common.js` | Общие функции витрины и админки (экранирование, постеры, сортировка) |
| `admin.js`, `admin.css` | Вход и общие части админки |
| `tmdb-helper.js` | Поиск постеров и трейлеров |
| `tg.js` | Режим Telegram Mini App (включается только внутри Telegram) |
| `bot/` | Telegram-бот на Cloudflare Workers и инструкция по запуску |
| `supabase/rls.sql` | Права: читать могут все, изменять только владелец |
| `supabase/functions.sql` | Атомарные операции: переименование и удаление списков, порядок ТОП-100 |

## Адреса витрины

Раздел, поиск, фильтры и открытый фильм сохраняются в адресе, поэтому ссылкой можно поделиться:

- `?view=movies` — раздел (`movies`, `series`, `cartoons`, `top100`, `new`, `recent`, `rewatch`)
- `?list=Любимое` — свой список
- `?q=матрица` — поиск
- `&genre=Драма&sort=rating_desc` — фильтр и сортировка
- `&film=42` — открытая карточка фильма

## Telegram

Сайт работает как Mini App: системная кнопка «Назад», цвета под тёмную тему, отступы под интерфейс Telegram, вибрация. Ссылки `startapp=film_42` и `startapp=view_top100` открывают нужный фильм или раздел. Бот и инструкция — в папке [`bot/`](bot/README.md).

## Безопасность

Ключ `anon` в `config.js` публичный по задумке Supabase. Изменять данные может только владелец: это обеспечивают политики RLS из `supabase/rls.sql`, а не скрытие ключа. Вход в админку — через Supabase Auth.
