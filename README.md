# MY COLLECTION

Коллекции фильмов, сериалов и мультфильмов: оценки, отзывы, трейлеры, ТОП-100 и свои списки. У каждого пользователя Telegram — своя коллекция, без регистрации.

**Сайт:** https://h0usehome.github.io/top_films_by_me/

## Как устроено

Статический сайт на GitHub Pages без сборки. Данные хранятся в Supabase, постеры и трейлеры ищутся через TMDB.

| Файл | Назначение |
|---|---|
| `index.html`, `app.js`, `style.css` | Публичная витрина |
| `admin.html` | Добавление и редактирование записей, порядок ТОП-100 (`#top100`); на телефоне — нижняя панель разделов |
| `database.html` | Вся база: поиск, удаление, автопоиск трейлеров |
| `lists.html` | Управление своими списками |
| `config.js` | Публичные ключи Supabase и TMDB |
| `common.js` | Общие функции витрины и админки (экранирование, постеры, сортировка) |
| `admin.js`, `admin.css` | Вход и общие части админки |
| `tmdb-helper.js` | Поиск постеров и трейлеров |
| `discover.js` | Быстрое добавление фильмов (первый запуск) и рекомендации |
| `tastes.js` | Интересы: экран с темами при первом входе, ряды «Вы любите: …» |
| `tg.js` | Режим Telegram Mini App и автоматический вход (включается только внутри Telegram) |
| `bot/` | Telegram-бот и страницы-превью ссылок на Cloudflare Workers, инструкция по запуску |
| `supabase/multiuser.sql` | Профили, `owner_id` у записей и списков, права «каждый меняет только своё» |
| `supabase/functions/telegram/` | Edge Function: вход из Telegram и карточки для «Поделиться» |
| `supabase/functions/tmdb/` | Edge Function: посредник к TMDB и YouTube — из России они часто недоступны напрямую; подборки, «похожие» и пакетные запросы |
| `supabase/recommendations.sql` | `tmdb_id` и `tmdb_type` у записей — для рекомендаций |
| `supabase/tastes.sql` | Таблица `profile_tastes`: выбранные интересы, видит только сам пользователь |
| `supabase/rls.sql`, `supabase/functions.sql` | Первые версии прав и атомарных операций (заменены `multiuser.sql`) |

## Адреса витрины

Раздел, поиск, фильтры и открытый фильм сохраняются в адресе, поэтому ссылкой можно поделиться:

- `?u=h0usehome` — чья коллекция (без параметра: своя в Telegram, иначе `DEFAULT_HANDLE` из `config.js`)
- `?view=movies` — раздел (`movies`, `series`, `cartoons`, `top100`, `new`, `recent`, `rewatch`, `account`, `discover`, `recs`)
- `?list=Любимое` — свой список
- `?q=матрица` — поиск
- `&genre=Драма&sort=rating_desc` — фильтр и сортировка
- `&film=42` — открытая карточка фильма

## Пользователи и Telegram

Сайт работает как Mini App: системная кнопка «Назад», цвета под тёмную тему, отступы под интерфейс Telegram, вибрация.

- **Вход без регистрации.** `tg.js` отправляет подписанные Telegram данные запуска (`initData`) в Edge Function `telegram`. Она проверяет подпись токеном бота, при первом входе создаёт пользователя и профиль (адрес коллекции — ник в Telegram) и выдаёт сессию Supabase. Владелец сайта может по-прежнему входить по email.
- **Нижнее меню:** слева Фильмы, Сериалы и Мульты, в центре главная, справа Подборки (ТОП, Лучшее 9–10, Новинки, Недавние, Пересматриваем, свои списки), ТОП и Аккаунт.
- **Аккаунт:** своя коллекция, «Поделиться коллекцией», вход в админку и профиль — имя, название коллекции и короткое имя для ссылки, с живым предпросмотром того, как коллекцию увидят друзья.
- **Добавление фильма:** «Быстрое заполнение» — начинаете вводить название, выбираете вариант из TMDB, и постер, год, тип (мультфильм определяется по жанру «анимация»), жанры, описание со слоганом, режиссёром, актёрами, страной и длительностью, а также трейлер подставляются сами; остаётся нажать оценку 1–10. Детали можно поправить вручную. Все запросы к TMDB идут через Edge Function `tmdb`.
- **Интересы.** При первом входе в свою коллекцию — экран «Что вам интересно?»: 45 «пузырьков» (немного жанров, в основном темы — супергероика, космос, ограбления, на реальных событиях…, плюс «русское», «французское», «кино 2010-х», «старое кино», «мини-сериалы»). Нужно выбрать от трёх или пропустить; потом экран не показывается, изменить — «Аккаунт → Мои интересы» или ссылка над рекомендациями. Тема — это фильтры TMDB discover; ключевые слова заданы английскими названиями и находятся через `search/keyword` по точному совпадению (id запоминаются на устройстве).
- **Первый запуск.** Новому пользователю вместо пустой страницы открывается «Соберём вашу коллекцию»: ряд «🔥 Сейчас в тренде» (тренды недели или популярное в выбранном жанре) и сетка «🏆 Культовые» (самое известное за всё время), вкладки «Фильмы / Сериалы», жанры и поиск. Нажал на постер — поставил оценку 1–10 или отложил в список «Хочу посмотреть»; постер, жанры, описание и трейлер подтягиваются сами. Тот же экран — «Добавить фильмы» (`?view=discover`) в «Подборках», меню и «Аккаунте».
- **Рекомендации** (`?view=recs` и ряд «Рекомендуем вам» на главной своей коллекции). Пока коллекция пуста — тренды и самое известное. Дальше — похожие на 10 фильмов из оценённых на 7+: состав меняется каждый день (выше шанс у высоких оценок и свежих), не больше трёх одного жанра; один фильм даёт не больше двух карточек в первой дюжине, выше — похожее сразу на несколько ваших и на любимые жанры; телефильмы и малоизвестное отсекаются. Плюс «Потому что вам понравился…», ряды «Вы любите: …» по интересам, лучшее в любимом жанре, тренды и культовое. Пока оценок меньше трёх, карточки по интересам идут в «Для вас» через одну, дальше — каждая четвёртая. Считаются в браузере, хранятся 6 часов и пересчитываются при новых оценках. У старых записей без `tmdb_id` он находится по названию и году и сохраняется.
- **Поделиться фильмом:** зажать карточку (на ПК — правая кнопка или «⋯») → меню «Поделиться / Скопировать ссылку / Трейлер / Открыть / Редактировать». Кнопка «Поделиться» есть и в карточке фильма.
  - В Telegram уходит сообщение с постером, оценкой, жанрами, цитатой из отзыва и кнопкой «Открыть карточку» (`savePreparedInlineMessage` + `shareMessage`, Telegram 8.0+). В старых клиентах — обычная ссылка.
  - Вне Telegram — системное меню «Поделиться» или копирование ссылки. Если задан `SHARE_BASE`, ссылка ведёт на страницу-превью воркера (`/f/42`), и в мессенджерах показывается постер с оценкой.
- Ссылки `startapp=film_42`, `startapp=u_handle`, `startapp=view_top100` открывают фильм, коллекцию или раздел.

### Настройка

1. Supabase → Edge Functions → Secrets: `TELEGRAM_BOT_TOKEN` (токен от @BotFather) и по желанию `TELEGRAM_APP_URL` (`https://t.me/<бот>/<app>`, если Mini App создан через `/newapp`).
2. Если вы уже владелец коллекции по email, свяжите её со своим Telegram **до первого входа из Telegram** (иначе создастся новый пустой аккаунт):
   ```sql
   update public.profiles set tg_id = <ваш id в Telegram> where handle = 'h0usehome';
   ```
3. В `config.js` — `TG_BOT_URL` и, после деплоя воркера, `SHARE_BASE`. Бот — в папке [`bot/`](bot/README.md).

## Безопасность

Ключ `anon` в `config.js` публичный по задумке Supabase. Читать коллекции может кто угодно, изменять — только свою: это обеспечивают политики RLS из `supabase/multiuser.sql` (`owner_id = auth.uid()`), а не скрытие ключа. Telegram id пользователей наружу не отдаётся (права на столбцы). Токен бота хранится только в секретах Edge Function и воркера.
