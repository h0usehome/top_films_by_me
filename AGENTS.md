# Правила работы с проектом

## Экономия токенов
- Отвечай кратко, детали предоставляй по запросу.
- Читай только файлы, относящиеся к задаче.
- Используй git diff для анализа изменений.
- Не выводи большие логи без необходимости.
- После выполнения задачи кратко описывай результат.

## Безопасность
- Не выполняй commit, push или deploy
  без подтверждения пользователя.
- Не изменяй файлы, не относящиеся к задаче.
- Не пропускай необходимые проверки ради экономии.
